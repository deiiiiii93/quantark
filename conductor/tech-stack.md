# Technology Stack: QuantArk

## Core Language & Runtime
*   **Python (>= 3.8):** The primary programming language, utilizing modern features such as type hints and dataclasses for a professional-grade API.

## Numerical & Scientific Computing
*   **NumPy:** Core library for high-performance array operations and linear algebra.
*   **SciPy:** Advanced numerical algorithms for optimization, integration, and statistical distributions used in pricing engines.

## Data Management
*   **Pandas:** For managing time-series market data, historical scenarios, and portfolio structures.
*   **PyArrow:** High-performance data processing and storage (Parquet) for large-scale risk calculations.
*   **OpenPyXL:** Support for interacting with Excel-based market data and reporting templates.

## Visualization & Reporting
*   **Matplotlib & Seaborn:** For generating professional, static charts and risk reports.
*   **Plotly & Kaleido:** For interactive risk dashboards and high-resolution export of visual assets.

## Infrastructure & Testing
*   **Pytest:** The primary framework for unit, integration, and regression testing.
*   **PyYAML:** For managing configuration files, stress scenarios, and environment settings.
*   **Dask:** For distributed and parallelized computation in large-scale Monte Carlo simulations and benchmarks.
