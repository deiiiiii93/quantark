Step 3

Bucketed Greeks make the hedge actionable

Scalar delta, rhoq, and vega compress away where the risk lives. The consolidated API returns normalized points, so each coordinate carries the same fields: derivative, reported, pnl, bump_size, and difference_mode.

Step 4

Finite differences are explicit

This example requests central mode per coordinate. That is the least biased finite-difference choice when both up and down bumps are valid.

central derivative = (PV_up - PV_down) / (2 * bump)

Per-coordinate overrides. The request sets futures delta, carry rhoq, and vol-tenor vega to central mode through difference_mode_overrides. The API still preserves older coordinate defaults when callers do not override them.

Model-aware bucket input

Keeping LocalVol, Heston, and SLV inputs distinct

The consolidated API does not pretend that every vega is the same bump. VOL_TENOR_VEGA directly bumps the pricing environment surface; MARKET_IV_VEGA delegates to the volatility-model risk backend, so LocalVol can rebuild a Dupire surface and Heston/SLV can use their calibration artifacts.
